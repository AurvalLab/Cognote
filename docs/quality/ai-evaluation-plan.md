# AI 评测计划

## 1. 目标

验证 Pipeline 是否稳定生成可校验、可追溯、对用户有价值的卡片，而不是只比较模型榜单。

## 2. 数据集

阶段 0 建立版本化评测集：

- 植物清晰图、模糊图、遮挡图、相似种、无法确定；
- 通用 fallback 样本；
- 文字记录；
- OCR 正负样本；
- 多物体、无关图片、异常格式；
- 高风险事实；
- 用户纠错和反例；
- 隐私内容只使用合成或获得明确授权的数据。

评测集按 `plant_image`、`general_image`、`text`、`uncertain` 分层报告，不能用通用图片样本稀释植物指标。文字集必须包含“事实整理导致原意改变”的反例；通用 fallback 必须检查越权输出品牌、价格、真伪或安全结论。

每条样本包含预期 card_type、必需/禁止事实、来源要求、可接受不确定性和人工评分规范。

## 3. 指标

### 结构稳定性

- 首次 Schema 通过率；
- 修复后通过率；
- `needs_review` 比例；
- 必需字段缺失率；
- 重复任务产生重复版本数（目标 0）。

### 识别与事实

- 领域分类准确率；
- 对象 Top-1/Top-k（仅有金标时）；
- 事实 precision/recall；
- 伪视觉证据率；
- 外部引用正确率；
- 信息不足时拒绝猜测率；
- 高风险违规结论率（目标 0）。
- 植物候选识别 Top-k 与拒绝猜测率；
- 植物视觉依据与像素内容一致率；
- 文字原文保真率（目标 100%）；
- 通用 fallback 越权承诺率（目标 0）。

### 用户价值

- 卡片接受率；
- 实质纠错率；
- 放弃率；
- 生成后保存耗时；
- 值得保留评分。

### 工程与成本

- P50/P95 总耗时和各阶段耗时；
- 超时、限流、供应商错误率；
- 每张接受卡片平均成本；
- 无效/放弃卡片成本；
- fallback 使用率。

## 4. 发布门禁

任一 Prompt、模型、Schema 或 Pipeline 变更必须：

1. 记录版本；
2. 跑固定回归集；
3. 与基线比较；
4. 高风险违规为 0；
5. 结构通过率和用户价值指标不显著回退；
6. 保存报告和真实命令输出。

## 5. 在线监控

只采集脱敏的阶段、版本、耗时、错误码、usage、成本和用户接受/纠错事件。原始图片和私密文本不进入通用监控平台。
