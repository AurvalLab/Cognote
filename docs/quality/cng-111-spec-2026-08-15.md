# CNG-111 生产创建入口规格冻结

> 日期：2026-08-15
>
> 基线：`master` / `2d59d19efdb7ba76da09c9d558f0dd943ad50018`
>
> 状态：实现前冻结

## 1. 唯一目标

让用户从生产时间线进入“记录此刻”，在无账号、无网络、无 AI 和无同步的条件下创建一条文字记录或一条单图片记录，并在保存成功后返回时间线看到该记录。

## 2. 范围

- 时间线提供清晰的“记录此刻”入口；
- 创建页支持文字与图片两种模式；
- 文字模式保存非空原文，保留用户输入，不做 AI 改写；
- 图片模式通过 Android 系统文档选择器导入单张 JPEG、PNG 或静态 WebP，并支持可选说明；
- Android 选择器把所选内容复制到应用缓存临时文件，Application 层完成准备、校验、原图落盘、Observation/LocalAsset/Outbox 同事务写入和临时文件清理；
- UI 区分选择/准备、保存中、校验失败、存储失败和持久化失败；
- 提交期间禁用重复提交；成功后返回时间线，时间线流负责显示新记录并允许进入详情；
- 取消系统选择器或返回创建页不产生 Observation、LocalAsset 或 Outbox。

## 3. 非范围

- 编辑既有记录；
- 自定义相机、拍照实现、批量导入、Share Sheet；
- EXIF 清洗承诺、图片替换、裁剪或压缩；
- `private_local` 入口或普通数据库之外的加密存储；
- 云 AI、上传、账号、同步消费、后台任务或远程分析；
- Dart package、数据库文件、Android applicationId、仓库名等技术标识迁移。

## 4. 数据与 API 影响

- 不修改 Drift schema，不生成或手工编辑 `cognote_database.g.dart`；
- 不新增依赖，不修改 `pubspec.yaml` 或受保护的 `pubspec.lock`；
- `CognoteApplication` 增加图片准备/保存 facade，Presentation 不直接持有 Repository 或数据库；
- 增加可注入的图片选择接口，生产默认实现通过固定 MethodChannel 调用 Android Storage Access Framework；
- Android 平台契约只返回应用缓存临时文件的 path、MIME type 和 display name，不返回图片内容、原始 URI 或用户路径给日志/分析；
- 现有 Observation、LocalAsset、FTS 与 Outbox 语义保持不变。

## 5. 失败路径

| 场景 | 预期 |
|---|---|
| 空白文字 | 页面内提示，不调用 Application |
| 系统选择器取消 | 保持可编辑，不显示失败，不产生写入 |
| 选择器已有请求 | 拒绝第二次请求，避免悬挂 result |
| 内容不可读或平台复制失败 | 显示“无法读取所选图片”，不写数据库 |
| 图片超过 25 MiB | 显示大小限制并清理临时副本 |
| 非支持格式、动态图、损坏或尺寸越界 | 显示图片校验错误，不写数据库并清理临时副本 |
| 本地空间/文件系统失败 | 显示本地存储错误，保留页面供重试 |
| 数据库/Outbox 事务失败 | 显示保存失败；沿用既有补偿语义，不误报成功 |
| 重复点击保存 | 只允许一次 in-flight 提交 |
| 异步完成时页面已销毁 | 不访问失效的 BuildContext/State |

## 6. 验收条件

- Widget 测试覆盖入口、文字 happy path、空白文字、图片 happy path、选择器取消、图片错误、保存错误、重复提交保护和成功返回导航；
- Application 测试证明图片 facade 使用本地身份、既有图片 Pipeline 与 Outbox，并在成功和失败时正确处理应用拥有的临时文件；
- 平台契约测试覆盖 MethodChannel 成功、取消和错误映射；
- format、analyze、定向测试、完整 Dart/Widget 测试与 `git diff --check` 通过；
- Android API 35 生产 UI 在飞行模式完成一轮文字/图片创建、浏览、搜索、删除和恢复；平台证据必须标明模拟器或物理机，不用 Widget 测试冒充 Android 证据。

## 7. 非功能边界

- 本地保存成功不依赖网络、账号、AI、同步或服务端；
- 用户原文与原图不进入日志、错误消息或平台通道诊断输出；
- 本任务不宣称 `private_local`、EXIF 已移除或云端能力可用；
- 所有异步 UI 操作显式处理异常和组件卸载。
