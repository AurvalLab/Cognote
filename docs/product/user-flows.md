# Mnora · 见藏 MVP 用户流程

## 1. 首次启动

```text
启动 → 创建匿名用户身份和设备身份 → 说明本地优先
→ 进入时间线空状态 → 记录此刻
```

不强制登录，不在首屏索取位置、相册全量访问或云端 AI 授权。

### 匿名身份升级

```text
触发登录场景 → 完成认证 → 建立账户主体
→ 提交匿名主体归并请求 → 服务端幂等迁移云端对象和额度流水
→ 客户端把本地 owner 映射切换为账户主体 → 校验数量与版本 → 完成
```

触发登录的场景仅包括：多设备同步、云端备份与恢复、匿名 AI 额度耗尽、订阅或购买套餐。归并中断后必须可重试；相同归并请求不得复制记录或重复扣减额度。

## 2. 离线创建图片记录

```text
记录此刻 → 拍照/选图 → 可选说明 → 本地事务保存
→ 时间线立即出现记录 → 标记“仅本地/未分析”
```

失败处理：

- 相机权限拒绝：允许改用相册或文字；
- 文件损坏：保留编辑页并说明原因；
- 本地空间不足：不声称保存成功，给出最小释放空间建议；
- App 强杀：已提交事务的数据必须恢复。

## 3. 文字记录

```text
记录此刻 → 输入文字 → 本地保存 → 可选发起 AI 整理
```

空白文本不允许提交；用户原文永远可见，不被 AI 摘要替换。

## 4. 发起云端 AI 分析

```text
打开未分析记录 → 点击“生成知识卡片”
→ 生成压缩分析副本/移除 EXIF → 端侧敏感性预检
→ 普通内容检查首次长期授权 / 敏感内容逐次确认
→ 预览待上传内容 → 可裁剪、打码、移除位置或取消
→ 上传 → 创建 AIJob → 展示阶段状态
```

授权拒绝或网络不可用时记录仍留在本地，用户可稍后重试。

`private_local` 不进入该流程。若用户请求云端专属能力，显示“此功能需要上传数据，私密记录暂不支持”，并提供继续保持私密或由用户主动转为普通记录的选择。

## 5. AI 成功

```text
任务完成 → 拉取不可变 CardVersion → 展示草稿和来源
→ 用户接受 / 修改后接受 / 放弃
→ 接受后生成有效卡片投影
```

放弃草稿不删除原始 Observation；重新生成产生新 CardVersion。

## 6. AI 失败

- `failed_retryable`：显示错误类别和重试按钮；
- `needs_review`：保存原始响应引用和校验错误，不显示伪造自由文本卡片；
- `failed_terminal`：保留原记录，允许手动创建标题和说明；
- `cancelled`：停止后续阶段，不删除已经保存的本地记录。

## 7. 用户纠错

```text
卡片详情 → 编辑字段 → 显示原值与新值 → 保存 Correction 事件
→ 重建有效卡片投影 → 搜索索引更新
```

纠错不覆盖 AI 原始版本。

## 8. 删除与恢复

```text
删除 → 二次确认范围 → 本地墓碑 → 从默认列表隐藏
恢复 → 新恢复操作 → 重新进入列表
```

未来启用同步后，删除和恢复均进入 Outbox。删除账号属于独立流程，不能与“删除单张卡片”混淆。

## 8.1 私密状态转换

```text
普通记录 → 用户选择转为私密 → 停止同步/AI → 发起云端级联删除
→ 删除已确认 → 迁入独立加密存储 → 显示“已转为仅本地”
```

删除失败时保持“转换异常/正在重试”，不得谎称已完全本地化。

```text
private_local → 用户主动转为普通 → 展示上传清单
→ 重新获得同步与 AI 授权 → 迁出私密存储 → 按用户选择上传
```

私密级别不随登录、换设备或打开同步自动改变。

## 9. MVP-B 多设备冲突

- 普通字段基于 `base_revision` 做乐观并发；
- 用户笔记冲突生成副本并要求选择；
- 标签使用添加/移除操作；
- 删除传播墓碑；
- AI 版本不可变；
- 冲突不能在后台静默覆盖。

## 10. 搜索与找回

MVP-A 使用本地时间线、标签和 FTS。搜索结果显示匹配片段；未来问答必须引用卡片和事实来源，没有证据时明确表示无法回答。
