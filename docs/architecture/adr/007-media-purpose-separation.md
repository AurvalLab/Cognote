# ADR-007：媒体按目的分离

- 状态：Accepted for specification v0.1
- 日期：2026-07-25

## 背景

本地原图、分析副本、缩略图和云备份是不同副本。

## 决策

AI 分析默认上传去 EXIF 的压缩副本并短期保留；原图备份独立授权。

`private_local` 记录及所有媒体/派生数据禁止进入上传路径；任何 ConsentSnapshot 都不能覆盖该策略。普通记录转私密时必须先完成云端级联删除，再确认私密状态。

## 结果

增加生命周期管理，但使隐私承诺和删除行为可执行。

## 复审触发条件

只有产品指标、容量数据、隐私要求或已验证的工程约束发生变化时复审；修改前必须提交替代 ADR。
