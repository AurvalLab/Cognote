# 隐私数据流与删除链路

## 1. 数据分类

| 类别 | 示例 | 默认位置 |
|---|---|---|
| 原始内容 | 图片、日记文字、语音（后续） | 本地 |
| 位置/EXIF | 经纬度、设备信息 | 不采集或本地 |
| 分析副本 | 压缩图片、必要文字 | 临时云端 |
| AI 派生数据 | CardVersion、Fact、来源 | 本地缓存；可选同步 |
| 行为事件 | 状态、耗时、错误码 | 最小化云端 |
| 凭证 | Session、刷新令牌 | 系统安全存储 |

## 2. 图片分析数据流

```text
本地原图
→ 本地生成压缩分析副本
→ 默认移除 EXIF
→ 端侧敏感性预检
→ 敏感内容逐次确认
→ 用户预览、裁剪、打码或移除位置
→ 校验 MIME/大小/SHA-256
→ 用户授权检查
→ 预签名上传至私有对象
→ AI Provider
→ 结构化结果
→ CardVersion 持久化
→ 立即触发删除，最迟 1 小时内清理分析副本
```

云端备份原图是独立路径，不因 AI 分析自动开启。

失败任务的分析副本最多保留 24 小时用于自动重试；取消任务立即删除。对象存储生命周期规则是兜底，不替代应用层主动删除。

## 3. 安全控制

- TLS；
- 私有桶和短期预签名 URL；
- object key 不含用户可识别文本；
- 服务端静态加密；
- 严格账号/对象级授权；
- 日志和错误追踪脱敏；
- 日志不得保存图片内容、Base64、永久 URL 或完整 EXIF；
- 不在客户端存储模型 API Key；
- 上传限制大小、MIME、像素和哈希；
- 导出文件有过期时间；
- 开发和测试数据不得复制真实用户内容。

## 3.1 数据地域

- MVP 的 API、数据库、对象存储、Redis/ARQ、日志和监控位于中国大陆。
- 中国大陆用户数据默认不复制、备份或传输到境外。
- 原始图片、精确位置、语音和私密笔记默认禁止跨境。
- 境外供应商不能作为无感备用 Provider。
- 未来跨境处理必须重新完成数据分类、必要性评估、用户告知、单独授权和适用的合规审查。
- 海外版本采用区域隔离部署；不同区域默认不复制用户数据。

## 4. 私密记录

`private_local` 默认行为：

- 不进入上传队列；
- 不调用云端 AI、OCR 或 Embedding；任何云端授权都不能穿透该边界；
- 不同步；
- 不进入云端备份、服务端日志、分析事件或崩溃报告；
- 不进入跨卡片回顾、画像和关联。

私密内容和全部派生数据存入独立本地加密存储，密钥由 iOS Keychain/Android Keystore 保护。App 后台预览、通知和系统备份不得泄露私密明文。未来端侧模型可在不改变该边界的前提下处理。

### 私密转换状态

```text
normal → localizing → private_local
              └→ localization_failed → localizing

private_local → declassifying → normal
```

`localizing` 必须停止后续同步和云 AI，并等待服务端级联删除原图、卡片、Embedding、Entity、Relation 等数据。只有删除确认后才进入 `private_local`；失败进入补偿队列并向用户显示异常。`declassifying` 只能由用户主动触发，并重新获取上传、同步和 AI 授权。

## 5. 删除链路

### 单卡删除

1. 本地墓碑；
2. 未来同步时传播删除；
3. 删除云端有效卡片、媒体副本和派生索引；
4. change log 保留必要墓碑；
5. 备份按公开窗口延迟清理。

### 账号删除

删除作业覆盖：

- PostgreSQL 主体数据；
- S3 对象和缩略图；
- pgvector/全文索引；
- Redis/ARQ 待处理任务；
- 临时导出；
- 分析与监控系统中的可识别标识；
- 第三方供应商可请求删除的内容。

作业必须可审计并向用户报告完成或剩余的法定/备份保留窗口。

### 删除状态机

```text
pending → processing → completed
              └→ failed → pending（补偿重试）
```

数据库记录 `deleted_at`、`deletion_status`、`deletion_attempts` 和下次重试时间。删除失败进入补偿队列并报警，禁止静默忽略。工作人员默认不能查看失败任务图片；人工排障需要用户单次明确授权。

## 6. 威胁与非承诺

- 云端 AI 需要服务端或供应商看到分析明文，不得宣称端到端加密；
- 第三方供应商可能有独立保留策略，授权页必须说明；
- 删除主库不等于备份立即物理消失；
- 私密 UI 标记不是安全边界，必须由上传和派生服务共同执行策略。
